# Expo version — pinned to SDK 54

This project is **pinned to Expo SDK 54** on purpose: Ting's phone runs Expo Go
v54.x, which only supports SDK 54 (SDK 55/56 show "incompatible, update Expo Go").
Do NOT bump the SDK above 54 until her Expo Go supports a higher version.

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before
writing any code.
